             Автоматизация тестирования веб-сервиса покупки туров
Проект представляет собой набор автотестов для веб-сервиса покупки туристических путевок. 
Включает в себя автоматизацию 13 позитивных и негативных сценариев для способа оплаты дебетовой картой (APPROVED карта).
В проекте проверяется реакция интерфейса (UI) и корректность записи статусов (APPROVED / DECLINED) в базу данных PostgreSQL.

Требования для начала работы:
Git: для работы с репозиторием
Docker Desktop: для развертывания базы данных PostgreSQL и веб-приложения
Яндекс.Браузер: для запуска UI-тестов
IDE: IntelliJ IDEA

Установка и запуск:
1. Запуск Docker: команда docker compose up
2. Запуск jar-файла aqa-shop.jar: команда java -jar artifacts/aqa-shop.jar
3. Запуск автотестов: команда ./gradlew clean test
