
       Автоматизация тестирования веб-сервиса покупки туров

                  Краткое описание проекта
Проект представляет собой набор автотестов для веб-сервиса покупки туристических путевок. 
Включает в себя автоматизацию 13 позитивных и негативных сценариев для способа оплаты дебетовой картой. 
Проект проверяет реакцию интерфейса (UI) и корректность записи статусов (APPROVED / DECLINED) в базу данных PostgreSQL.

Для запуска проекта на локальном ПК установлены:
1.Git: для работы с репозиторем.
2.Docker Desktop: для развертывания базы данных PostgreSQL и веб-приложения.
3.Яндекс.Браузер: для запуска UI-тестов.
IDE: IntelliJ IDEA.

Пошаговый процесс установки и запуска:
1.Запуск Docker: команда docker compose up
2.Запуск jar-файла aqa-shop.jar: команда  java -jar artifacts/aqa-shop.jar
3.Запуск автотестов: команда ./gradlew clean test
